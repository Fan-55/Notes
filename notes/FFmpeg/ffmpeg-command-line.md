#

Print help:

| option        |                   |
| ------------- | ----------------- |
|  -h           | basic options     |
|  -h long      | more options      |
|  -h full      | print all options |
|  -h type=name | print all the options for the named decoder/encoder/demuxer/muxer/filters/bsf |

- usage:

```
ffmpeg [options] [input options] -i input_file [output options] output_file
```
