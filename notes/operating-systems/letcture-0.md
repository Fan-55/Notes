## Batch system

When a job is doing IO operation, its CPU is idle and cannot execute other jobs.

## Multi-programming system

When a job is doing IO operation, the CPU can execute other jobs. Multiple programs are loaded to main memory unlike batch system.

Spooling (simultaneous peripheral operation on-line):
- I/O is done with no cpu intervention
- CPU is notified when I/O is done

## Time-sharing (multi-tasking) system

For user interactions.
