# Chapter 1

An operating system is a software that manage a computer's hardware.

resource utilization – how various software and hardware resources are shared.

A computer system has many resources that may be required to solve a problem: CPU time, memory space, storage space, I/O devices, and so on. The operating system acts as the manager of these resources. The operating system decides how to allocate them to specific programs and users so that it can operate the computer system efficiently and fairly.

The fundamental goal of computer systems is to execute programs and to make solving user problems easier. Computer hardware is constructed toward this goal but it requires the application programs to make it easy to use. These application programs require common operations such as those controlling I/O devices. The common functions of controlling and allocating resources are then brought together into one piece of software: the operating system.

We have no universally accepted definition of what is part of the operating system. Common definition:

- It includes everything a vendor ships when you order the "operating system".

- The one program that is running at all times on the computer – kernel. If we consider operating system as the kernel, there are two other types of programs: systems programs and application programs. The system programs are associated with the operating system while the application programs are not.

A device controller maintains some local buffer storage and a set of special-purpose registers. The device controller is responsible for moving the data between the peripheral devices that it controls and its local buffer storage.
